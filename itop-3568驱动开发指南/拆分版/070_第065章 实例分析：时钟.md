# 第065章 实例分析：时钟

时钟（Clock）在硬件系统中用于提供同步与定时信号，是协调各类设备正常运行的重要基础。在设备树中，时钟相关信息用于描述时钟源的配置及其连接关系。时钟可以分为两个主要角色：时钟生产者（clock provider）和时钟消费者（clock consumer）。
## 65.1 时钟生产者
时钟生产者是用于生成和输出时钟信号的模块，它可以是时钟控制器、PLL、时钟发生器等。在设备树中，时钟生产者通过时钟节点定义，其关键属性如下：（1）clock-cells代表时钟输出的路数。当clock-cells 值为0 时表示仅有一路时钟输出，值大于等于1 时表示输出多路时钟。具体示例如代码清单65.1 所示。代码清单65.1
```c
示例1：单个时钟
osc24m: osc24m {
    compatible = "clock";
    clock-frequency = <24000000>;
    clock-output-names = "osc24m";//输出时钟的名字
    #clock-cells = <0>;
};
示例2：多个时钟
clock: clock {
    #clock-cells = <1>;
    clock-output-names = "clock1", "clock2";//输出时钟的名字
};
```
（2）clock-frequency用于指定时钟输出频率（单位：Hz）。例如指定时钟频率为24000000 的具体示例如代码清单65.2 所示。代码清单65.2
```c
osc24m: osc24m {
    compatible = "clock";
    clock-frequency = <24000000>;
    clock-output-names = "osc24m";
    #clock-cells = <0>;
};
```
（3）assigned-clocks 和assigned-clock-rates

这两个属性一般成对使用，当输出多路时钟时，为每路时钟进行编号。具体示例如代码清单65.3 所示。代码清单65.3
```c
cru: clock-controller@fdd20000 {
        #clock-cells = <1>;
        //输出CLK_RTC_32K 和ACLK_RKVDEC_PRE 两路时钟
        assigned-clocks = <&pmucru CLK_RTC_32K>, <&cru ACLK_RKVDEC_PRE>;
        //CLK_RTC_32K 时钟信号频率为32768，ACLK_RKVDEC_PRE 时钟信号频率为300000000
        assigned-clock-rates = <32768>, <300000000>;
};
```
（4）clock-indices用于指定索引号（index）。如果不提供这个属性，那么clock-output-names 和index 的对应关系就是0，1，2，…，如果这个对应关系不是线性的，可以通过clock-indices 属性来定义映射到clock-output-names 的index，使用示例如代码清单65.4 所示。代码清单65.4
```c
scpi_dvfs: clocks-0 {
    #clock-cells = <1>;
    clock-indices = <0>, <1>, <2>;
    clock-output-names = "atlclk", "aplclk", "gpuclk";//atlclk 索引号为0，aplclk 索引号为1，gpuclk 索引号为2
};
scpi_clk: clocks-1 {
    #clock-cells = <1>;
    clock-indices = <3>;
    clock-output-names = "pxlclk"; //pxlclk 索引号为3
};
```
（5）assigned-clock-parents用与指定时钟源的父时钟。具体使用示例如代码清单65.5 所示。代码清单65.5
```c
clock: clock {
    assigned-clocks = <&clkcon 0>, <&pll 2>;
    assigned-clock-parents = <&pll 2>; //指定clkcon 0 时钟源的父时钟为pll 2
    assigned-clock-rates = <115200>, <9600>;//clkcon 0 时钟频率为115200，pll 2 时钟频率为9600
};
```
## 65.2 时钟消费者

时钟消费者是依赖时钟信号的硬件设备或模块。在设备树中，时钟消费者通过引用时钟生产者节点提供的时钟源来获取时钟信号。其关键属性有clocks 和clock-names 两个，用来指定使用的时钟源和消费者中时钟的名字。一个时钟消费者示例如代码清单65.6 所示。代码清单65.6
```c
clock: clock {
    clocks = <&cru CLK_VOP>; //指定该节点使用的时钟源是cru 提供的CLK_VOP 时钟
    clock-names = "clk_vop"; //设置时钟源名字为clk_vop
};
```
