# 第105章 设备注册流程分析实验

本章节深入分析设备注册的流程，从代码的层面来理解设备的注册过程。在Linux 内核的设备模型中，注册设备是将硬件设备纳入内核管理的关键步骤。device_register()函数将一个struct device 实例添加到内核设备模型中，完成sysfs 目录创建，父设备关联，总线绑定，驱动匹配等操作。device_register()函数原型定义在drivers/base/core.c文件中，如代码清单105.1 所示：代码清单105.1
```c
int device_register(struct device *dev)
{
       device_initialize(dev);
       return device_add(dev);
}
EXPORT_SYMBOL_GPL(device_register);
```
通过代码清单105.1 可以看出device_register()函数首先调用了device_initialize()函数初始化设备的基础成员。device_initialize()函数实现如代码清单105.2 所示。代码清单105.2
```c
void device_initialize(struct device *dev)
{
    dev->kobj.kset = devices_kset;//关联全局设备集合
    kobject_init(&dev->kobj, &device_ktype); //初始化内核对象，绑定设备释放
    INIT_LIST_HEAD(&dev->dma_pools);//初始化DMA 池链表头
    mutex_init(&dev->mutex);//初始化互斥锁
    lockdep_set_novalidate_class(&dev->mutex);
    spin_lock_init(&dev->devres_lock);//初始化自旋锁
    INIT_LIST_HEAD(&dev->devres_head);//初始化设备资源链表头
    device_pm_init(dev);//初始化电源管理
    set_dev_node(dev, -1);//初始设备节点号，-1 表示未分配具体设备节点
    #ifdef CONFIG_GENERIC_MSI_IRQ
    INIT_LIST_HEAD(&dev->msi_list);
    #endif
    INIT_LIST_HEAD(&dev->links.consumers);
    INIT_LIST_HEAD(&dev->links.suppliers);
    INIT_LIST_HEAD(&dev->links.needs_suppliers);
    INIT_LIST_HEAD(&dev->links.defer_hook);
    dev->links.status = DL_DEV_NO_DRIVER;//初始连接状态是设备未绑定驱动
}
EXPORT_SYMBOL_GPL(device_initialize);
```

代码清单105.1 中接着调用device_add()函数，此函数负责完成设备的添加，函数实现的流程可以拆解成6 个关键步骤。步骤一检查设备的基本信息，如代码清单105.3 所示：代码清单105.3
```c
int device_add(struct device *dev)
{
    struct device *parent;//指向父设备的指针
    struct kobject *kobj;//内核对象（用于sysfs 文件系统的设备节点管理）
    struct class_interface *class_intf;//设备类接口
    int error = -EINVAL;
    struct kobject *glue_dir = NULL;
    // 获取设备的引用
    dev = get_device(dev);
    if (!dev)
        goto done;
     //检查设备私有数据结构是否已初始化
    if (!dev->p) {
        error = device_private_init(dev);
        if (error)
             goto done;
    }
    //静态分配设备的名称初始化
    if (dev->init_name) {
        // 初始化设备的名称
        dev_set_name(dev, "%s", dev->init_name);
        dev->init_name = NULL;
    }
    /* 子系统可以指定简单的设备枚举*/
    if (!dev_name(dev) && dev->bus && dev->bus->dev_name)
        // 如果设备的名称为空，并且设备所属总线的名称不为空，则设置设备名称
        dev_set_name(dev, "%s%u", dev->bus->dev_name, dev->id);
    if (!dev_name(dev)) {
        error = -EINVAL;
        goto name_error;
    }
    pr_debug("device: '%s': %s\n", dev_name(dev), __func__);
```
